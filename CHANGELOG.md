# Changelog

## 0.1.0 — 2026-10-31
- First executable donor-held-out cell-type benchmark (strict donor disjointness).
- Training-fold-only HVG; raw-count validation; CSV and optional h5ad support.
- Logistic regression, random forest, MLP, optional compact Transformer baselines.
- Reports: per-donor, per-class, predictions, fold manifest, configuration and HTML.
- Synthetic example, deterministic seeds, regression tests and continuous integration.
