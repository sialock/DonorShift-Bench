# Synthetic split comparison example

These files were generated by DonorShift-Bench v0.2.0 with the bundled artificial dataset (`examples/data/synthetic_sc_counts.csv`). They are saved as a small, inspectable output example. **No patient data are used here.**

```bash
donorshift compare \
  --input examples/data/synthetic_sc_counts.csv \
  --output results/comparison \
  --models logreg random_forest \
  --top-genes 48 --bootstrap 200 \
  --test-fraction 0.2 --random-repeats 3 \
  --dataset-kind synthetic --seed 42
```

The comparison is descriptive. The training sizes differ between the protocols, and the synthetic within-donor cell split happens to score *below* the donor-held-out evaluation. This should not be read as evidence that grouping is unnecessary or that a real cohort would behave the same way.

To regenerate all files, including the standalone HTML report and full nested donor-held-out results, run the command above locally.
