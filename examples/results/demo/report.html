Leakage controls

Each donor appears only in testing for its outer fold. Gene detection, selection and transformations are fit on training donors only. All hyperparameters are fixed, without optimizing on the held-out donors. See fold_manifest.json for the selected genes in each fold.

Interpretation and limitations

  • Synthetic demo is not a scientific benchmark
  • Single held-out donor folds do not establish prospective clinical validity
  • Macro F1 uses cell types present in each test donor
  • Prediction confidence is uncalibrated
  • HVG heuristic is not Seurat or Scanpy batch-aware HVG

Bootstrap intervals in summary.json are descriptive donor-resampling intervals. This report is not a clinical validation.
